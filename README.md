# RaceDay Event Management System (Part 1 - Planning)

## System Description
RaceDay is a web-based event management platform designed for South Africa’s running, walking, and cycling community.  
It allows organisers to create and manage events, categories, and participant results, while participants can browse events, enrol, and track their race history.

## Roles
- **Organiser**: Can create, edit, and delete events, manage categories, capture participant results, and view enrolments.  
- **Participant**: Can register, browse events, enrol in categories, view their enrolments, and track personal results.
